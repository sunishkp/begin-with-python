Project 1: Number Guessing Game

Goal: Build a game where the computer picks a random number and the player tries to guess it.

Beginner: This is a simple project that reinforces conditional statements, user input, and loops.

Steps to Build:

  1. Import the random module.
  2. Generate a random number between 1 and 100.
  3. Ask the user to guess the number using input().
  4. Use a loop to check if the guess is too high or too low.
  5. Give hints and repeat until the correct number is guessed.
  6. Congratulate the player.
View Solution Code (click to expand) 

            import random

            secret_number = random.randint(1, 100)
            guess = int(input("Guess a number between 1 and 100: "))

            while guess != secret_number:
                if guess < secret_number:
                    print("Too low!")
                else:
                    print("Too high!")
                guess = int(input("Try again: "))

            print("Congratulations! Your guess is correct!")

Project 2: Basic Calculator

Goal: Create a calculator that performs addition, subtraction, multiplication, or division.

Beginner: This project is a fun way to practice arithmetic operations, conditionals, and loops.

Steps to Build:

  1. Display a menu with 4 operation choices.
  2. Ask the user to select one (1/2/3/4).
  3. Get two numbers from the user.
  4. Use if/elif to decide which operation to run.
  5. Display the result of the operation.
  6. Handle division by zero for safety.
View Solution Code (click to expand) 
print("Choose an operation:")
    print("1. Add")
    print("2. Subtract")
    print("3. Multiply")
    print("4. Divide")

    choice = input("Enter choice (1/2/3/4): ")
    num1 = float(input("Enter first number: "))
    num2 = float(input("Enter second number: "))

    if choice == '1':
        print("Result:", num1 + num2)
    elif choice == '2':
        print("Result:", num1 - num2)
    elif choice == '3':
        print("Result:", num1 * num2)
    elif choice == '4':
        if num2 != 0:
            print("Result:", num1 / num2)
        else:
            print("Cannot divide by zero!")
    else:
        print("Invalid input.")

Project 3: To-Do List Manager

Goal: Create a simple to-do list program where users can add, view, and remove tasks.

Intermediate: This project helps practice lists, loops, conditionals, and menu-driven programs in Python.

Steps to Build:

  1. Create an empty list to store tasks.
  2. Display a menu with options to add, remove, view, or quit.
  3. Use a loop so the menu keeps appearing until the user exits.
  4. Add tasks into the list using append().
  5. Remove tasks by checking if they exist in the list.
  6. Display all current tasks with numbering.
View Solution Code (click to expand) 
tasks = []

    while True:
        print("\nTo-Do List Manager")
        print("1. View Tasks")
        print("2. Add Task")
        print("3. Remove Task")
        print("4. Quit")

        choice = input("Enter choice: ")

        if choice == '1':
            if len(tasks) == 0:
                print("No tasks available.")
            else:
                print("\nTasks:")
                for i in range(len(tasks)):
                    print(f"{i + 1}. {tasks[i]}")

        elif choice == '2':
            task = input("Enter a new task: ")
            tasks.append(task)
            print("Task added.")

        elif choice == '3':
            task = input("Enter task to remove: ")

            if task in tasks:
                tasks.remove(task)
                print("Task removed.")
            else:
                print("Task not found.")

        elif choice == '4':
            print("Goodbye!")
            break

        else:
            print("Invalid choice.")

Project 5: Banking System

Goal: Create a simple banking system that allows deposits, withdrawals, and balance checking.

Intermediate: This project practices loops, conditionals, arithmetic operations, and menu systems.

Steps to Build:

  1. Create a starting balance variable.
  2. Display banking options in a menu.
  3. Allow the user to deposit money into the account.
  4. Allow withdrawals only if enough balance exists.
  5. Display the updated balance after transactions.
  6. Use a loop so the menu repeats until the user exits.
View Solution Code (click to expand) 
balance = 1000

    while True:
        print("\nBanking System")
        print("1. Check Balance")
        print("2. Deposit")
        print("3. Withdraw")
        print("4. Exit")

        choice = input("Enter choice: ")

        if choice == '1':
            print("Current Balance: $", balance)

        elif choice == '2':
            amount = float(input("Enter deposit amount: "))
            balance += amount
            print("Deposit successful.")

        elif choice == '3':
            amount = float(input("Enter withdrawal amount: "))

            if amount <= balance:
                balance -= amount
                print("Withdrawal successful.")
            else:
                print("Insufficient funds.")

        elif choice == '4':
            print("Exiting system.")
            break

        else:
            print("Invalid choice.")

Project 6: Word Counter

Goal: Create a program that counts the number of words and characters in a sentence.

Intermediate: This project practices string methods, lists, and basic text processing.

Steps to Build:

  1. Ask the user to enter a sentence.
  2. Use split() to separate the sentence into words.
  3. Count the number of words using len().
  4. Count the total number of characters.
  5. Display both results to the user.
View Solution Code (click to expand) 
sentence = input("Enter a sentence: ")

    words = sentence.split()

    word_count = len(words)
    character_count = len(sentence)

    print("Number of words:", word_count)
    print("Number of characters:", character_count)
