🔁 Introduction to Loops in Python

Loops help you repeat actions without writing code multiple times. Python has two main types: for loops and while loops.

📍 for Loop Example:

for i in range(5):
    print("Hello!")

This will print "Hello!" five times.

📍 while Loop Example:

count = 0
      while count < 3:
          print("Learning Python!")
          count += 1

This runs while the condition count < 3 is true.
